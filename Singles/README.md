# Singles maps overview

## AmideBB and AmideSC  (Kimvana, GMAP developer)
(**Come with GMAP**) These two maps are used for modelling the IR spectra of the Amide I band for proteins. AmideBB models the backbone amide groups, while AmideSC models the sidechain groups. Note that these two require the 'proteincore.txt' file from the main maps dir (one directory up from here).

## Tryptophan_1La (GHlacour, GMAP developer)
(**Comes with GMAP**) This map is intended to use for the tryptophan 1La transition in proteins.

## Water (GHlacour, GMAP developer)
(**Comes with GMAP**) This map is intended to use with water O (smiles notation). It can be applied both for H2O and HOD, but gives the frequency of the OH stretch.
