# Singles maps overview

## AmideBB and AmideSC  (Kimvana, GMAP developer)
![Static Badge](https://img.shields.io/badge/spectrum-infrared-indianred?style=flat&labelColor=dimgray)
![Static Badge](https://img.shields.io/badge/MD-all%20atom-forestgreen?style=flat&labelColor=dimgray)
![Static Badge](https://img.shields.io/badge/moltype-protein-blueviolet?style=flat&labelColor=dimgray)
![Static Badge](https://img.shields.io/badge/GMAP-Includes-sandybrown?style=flat&labelColor=dimgray)

These two maps are used for modelling the IR spectra of the Amide I band for proteins. AmideBB models the backbone amide groups, while AmideSC models the sidechain groups. Note that these two require the 'proteincore.txt' file from the main maps dir (one directory up from here).

## BChl_c (GijsCodesBert)
![Static Badge](https://img.shields.io/badge/spectrum-electronic-firebrick?style=flat&labelColor=dimgray)
![Static Badge](https://img.shields.io/badge/MD-united%20atom-lawngreen?style=flat&labelColor=dimgray)
![Static Badge](https://img.shields.io/badge/moltype-chlorophyll-turquoise?style=flat&labelColor=dimgray)
![Static Badge](https://img.shields.io/badge/GMAP-Includes-sandybrown?style=flat&labelColor=dimgray)

This map is designed for the organic pigment Bacteriochlorophyll c. It has been verified for an assembly of these molecules into a triple-walled tube.
